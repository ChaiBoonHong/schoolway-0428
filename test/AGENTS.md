# Test Instructions

Agent-Contract-Version: 1

Read the repository root `AGENTS.md` first.

- Test legitimate behavior and the closest denial/failure path.
- UI changes require phone, tablet, and desktop coverage and light/dark coverage where practical.
- Accessibility checks must include semantics, keyboard activation, reduced motion, and 200% text scaling.
- Security tests must prove cross-role and cross-owner access is denied, not only that authorized access succeeds.
- Tests must be deterministic and must not require production credentials or production data.
